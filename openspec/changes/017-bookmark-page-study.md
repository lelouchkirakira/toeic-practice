# 書籤頁的字可以直接去背

## 變更內容

016 讓背單字頁側欄的書籤可以點去背，但書籤頁本身還是只能移除或整批複習。同一份資料在兩個地方行為不一樣。

這次讓書籤頁的每一筆也能點：點了跳到背單字頁，那個字就是第一張。

## 影響範圍

- `lib/review-handoff.ts`：既有的複習旗標旁邊加一個「指定第一張」的暫存，存整筆單字，讀完即清
- `app/bookmarks/page.tsx`：單字本身改成按鈕，點了寫暫存再導到背單字頁；右邊的移除鍵不變
- `app/vocabulary/page.tsx`：進頁時若有指定的字，抽完卡之後把它放到第一張；那個字本來就抽到的話是移到最前面不是複製

用 sessionStorage 而不是查詢字串，理由跟 010 一樣：`/vocabulary` 是靜態預先產生的頁面，改讀查詢字串要加 Suspense 並讓整頁轉成動態算繪。

## 測試計畫

1. 書籤頁點任一個單字，跳到背單字頁且第一張就是那個字，書籤圖示是實心
2. 評完第一張之後接著是正常抽到的字，總數正確
3. 直接從導覽列進背單字頁，不會殘留上一次指定的字
4. 移除鍵仍然只移除，不會跳頁
5. 鍵盤可以 Tab 到單字並用 Enter 觸發
