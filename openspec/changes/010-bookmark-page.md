# 書籤頁

## 變更內容

009 加了書籤，但標記完之後沒有地方看到自己標了哪些字。目前只能打開「只抽書籤」重新抽卡，一次看一張，看不到全貌，也不知道總共標了幾個。

這次加一個獨立的書籤頁，導覽列放在「背單字」右邊。頁面列出這個學習者標記過的所有字，最新標的排前面，每一列可以直接移除，頁首有一個「用書籤複習」直接跳去背單字並自動打開只抽書籤。

## 影響範圍

### 後端（dashai-go 的 toeic module）

- 新增 `GET /vocabulary/bookmarks?limit=`：依 `X-Learner-Id` 取出標記過的字，依標記時間新到舊排序，回 `{words, total}`。`limit` 預設 200、上限 500，`total` 是實際總數，超過 limit 時前端據此提示
- 沒帶 `X-Learner-Id` 回空清單與 total 0，與其他讀取類 endpoint 一致，不回別人的

### 前端（web/）

- 新頁 `app/bookmarks/page.tsx`
- `components/site-nav.tsx`：導覽列在「背單字」與「聽力」之間插入「書籤」
- `lib/api.ts`：`fetchBookmarks(limit)`
- `app/vocabulary/page.tsx`：進頁時若帶著複習指示就直接以只抽書籤的條件載入

### 從書籤頁跳去複習的作法

書籤頁按下「用書籤複習」時在 sessionStorage 寫一個旗標再導頁，背單字頁在既有的首次載入 effect 裡讀取並清掉，讀到就把開關打開、第一次抽卡就帶著書籤條件。

不用查詢字串是因為 `/vocabulary` 目前是靜態預先產生的頁面，改讀 `useSearchParams` 要加 Suspense 並讓整頁轉成動態算繪；旗標寫法只動十行左右，也不會讓第一次抽卡白抽一次再重抽。

### UI 規格

- 頁首一行：「共 N 個」與「用書籤複習」按鈕，N 是後端回的 total
- 一個字一列：單字、音標、詞性、難度標籤、中文釋義（沒有中文就顯示英文），右側一個移除按鈕（書籤圖示，實心）
- 移除是先改畫面再送請求，失敗退回原狀並顯示錯誤，與卡片上的行為一致
- 一個書籤都沒有時顯示「還沒有標記任何單字，去背單字頁在卡片上點書籤」，並附一個連到背單字的連結
- total 大於實際列出的筆數時，列表下方一行提示只顯示最新的幾筆
- 列表不用表格，用一般列表排版，手機單欄

## 測試計畫

1. 標記三個字之後打開書籤頁，三個都在，最新的排最前面
2. 頁首的「共 N 個」與實際筆數一致
3. 在書籤頁移除一個，列表少一列，重新整理後仍然少那一列
4. 移除到零筆時顯示空狀態與連結
5. 按「用書籤複習」跳到背單字頁，開關已經是開的，第一次抽卡就只有書籤的字，且只發一次抽卡請求
6. 複習過一輪後再進背單字頁（直接點導覽列），開關是關的，不會黏住
7. 換一組學習者代號，書籤頁是空的
8. 沒帶 `X-Learner-Id` 呼叫 endpoint 回空清單不是別人的資料
9. 導覽列「書籤」在「背單字」右邊，目前頁面時有 `aria-current`
10. 手機寬度下導覽列六個項目不擠成兩行、列表不橫向捲動
