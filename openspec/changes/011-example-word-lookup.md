# 例句點字查單字

## 變更內容

例句現在只有英文。遇到不認識的字要自己跳出去查，閱讀就斷在那裡，例句等於只能看懂的人才用得到。

這次讓例句裡的字可以查：桌機滑鼠移上去、手機點一下，出現一張小卡，內容是音標、詞性、中英釋義、詞形變化，加一個發音按鈕。

資料全部來自現有字庫，不接外部字典也不叫模型。實際比對過：全部例句拆成單字共出現 115,824 次，字庫（含詞形變化）直接對得上 112,267 次，覆蓋率 96.9%；把 `company's` 這種所有格與 `don't` 這種縮寫還原之後升到 98.4%。對不上的是 `startup`、`hr`、`ceo` 這類，一百個字裡一到兩個。

發音也不必另外產檔。6,228 個字的美英澳三種口音音檔在 2026-09-21 就產好放在 Vercel Blob，小卡直接用跟正面卡片同一組檔案。

## 影響範圍

### 後端（dashai-go 的 toeic module）

- 新增 `POST /vocabulary/lookup`：body 收 `tokens`（字串陣列，上限 60），回傳 `{entries: {原 token: Word}}`，對不上的 token 不出現在結果裡
- 正規化在後端做，只有一份：轉小寫、去掉結尾的 `'s`、還原 `n't` `'re` `'ll` `'ve` `'d` `'m`，再比對 `word` 與 `inflections`
- 同一個 token 同時對到本字與別的字的詞形變化時，本字優先
- 不需要 `X-Learner-Id`，查的是公共字庫不是個人資料

### 前端（web/）

- `components/vocabulary/word-card.tsx`：例句改成逐字渲染，查得到的字是按鈕，查不到的是純文字
- 新元件 `components/vocabulary/word-popover.tsx`：小卡內容，桌機與手機共用
- `lib/api.ts`：`lookupTokens(tokens)`
- 卡片翻面顯示例句時才查一次，結果留在這張卡的記憶體裡，翻來翻去不重查

### 互動規格

- 桌機（`(hover: hover) and (pointer: fine)`）：滑鼠移上去 150 毫秒後開，移開就關，小卡貼在那個字下面
- 手機與觸控：點一下從底部升起面板，右上角有關閉鍵，面板不蓋住正在讀的那一行
- 只接點擊，不接長按，手機的選字反白維持原生行為不受影響
- 例句區塊不在翻面按鈕裡面，點例句的字不會把卡片翻回正面（現況如此，實作不要改動這個結構）
- 每個可點的字有內距，行高放寬，手指點得到
- 鍵盤：一句話是一個 Tab 停留點，進去之後用左右方向鍵在字之間移動，Enter 或空白鍵開小卡，Esc 關掉。不讓十幾個字各自佔一個 Tab 停留點，不然鍵盤使用者要按很多次才能走到下面的熟練度按鈕
- 例句裡用粗體標著的目標字不可點，那就是這張卡本身，翻面時釋義已經在上面
- 對不上字庫的字維持純文字，不做成按鈕，不要讓人點了沒反應

### 小卡內容

單字、音標、詞性、中文釋義（沒有中文就英文）、詞形變化、發音按鈕（沿用卡片正面的口音設定）。音檔缺檔時不顯示發音按鈕。

## 測試計畫

1. 翻面看到例句，`company's` 這種所有格與 `don't` 這種縮寫都可點，內容對到原形
2. `startup`、`hr` 這類查不到的字是純文字，點下去沒有任何事發生
3. 粗體的目標字不可點
4. 桌機滑鼠移上去開、移開關，移動很快掃過整句不會連開好幾張
5. 手機點一下從底部升起，關閉鍵可以關，長按仍然可以選字複製
6. 小卡的發音播得出聲音，換口音之後播的是對應口音的檔
7. 鍵盤 Tab 進例句只停一次，左右鍵能移動，Enter 開、Esc 關，關掉之後焦點回到原來那個字
8. 同一張卡翻兩次只發一次查詢請求
9. 例句有兩句以上時，兩句的字都查得到
10. 後端斷線時例句仍然正常顯示，只是不可點，不要整塊消失
11. 既有的翻面、發音、熟練度、書籤行為不受影響
