# 側欄的字可以點去背

## 變更內容

015 讓例句小卡可以跳去背那個字，但右側欄的「剛查過」與「書籤」還是死的，看到想背的字只能重抽或去書籤頁。兩邊行為不一致。

這次把側欄的每一筆改成可以點，點了跟小卡那顆按鈕一樣：那個字插到目前這個位置，評完回到原本那張。

## 影響範圍

- `components/vocabulary/study-panel.tsx`：每一筆由 `li` 內的純文字改成整塊可點的按鈕，兩行排版不變；加 `onPick` 由外面傳進來
- `app/vocabulary/page.tsx`：把既有的 `jumpTo` 傳給側欄，插卡邏輯沿用不重寫

兩份清單的資料本來就是完整的單字（書籤清單與例句查詢都回整筆），所以插進去就能直接背，不用再打 API。

## 測試計畫

1. 點「剛查過」的任一筆，卡片換成那個字，進度加一
2. 點「書籤」的任一筆，行為相同，且書籤圖示是實心
3. 點目前正在背的那個字，不會多出一張重複的卡
4. 鍵盤可以 Tab 到側欄每一筆並用 Enter 觸發
5. 手機寬度側欄仍然隱藏，其餘行為不變
