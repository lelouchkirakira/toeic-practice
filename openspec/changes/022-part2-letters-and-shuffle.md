# Part 2 唸出 A B C 並打亂回答順序

## 變更內容

Part 2 一題是一個合好的音檔：問句、三個回答依序唸完，中間只有停頓，沒有唸字母。練習時沒有答案卡可以對照，聽的人要自己數第幾個回答，容易亂掉；而且題庫只有 25 題，同一題重複練幾次就會記成「答案是 B」。

官方考試的錄音是不唸字母的（ETS 官方 practice test 的錄音腳本裡，(A)(B)(C) 跟說話者代號同一種寫法，是標記不是台詞）。但練習網站普遍會唸，所以做成開關，預設唸。

## 做法

不重新合成任何一句話。

- `scripts/split_part2_audio.py`：下載現有 25 個檔，用 ffmpeg 依靜音切成問句與三個回答。25 題全部剛好偵測到三段靜音。另外用 SSML 逐字唸的方式合成 A B C 三個字母檔，所有題目共用
- 切出來的 103 個檔共 1.8 MB，放在 `web/public/audio/`，跟著網站部署。原本的音檔在 Vercel Blob，這批改放 public 是因為上傳 Blob 需要的權杖目前不在環境裡，而 1.8 MB 放在 repo 裡不構成負擔；之後權杖補回來可以再搬
- `lib/part2-sequence.ts`：依序播問句、停頓、字母、回答。全程用同一個 Audio 元件換來源，手機在第一次點擊之後就放行，接續播放不會再被擋
- 出題時每題決定一次三個回答的播放順序，畫面上的 A B C 指的是播出來的順序，對答案時換算回原題的選項字母；檢討畫面照當時播出的順序列，字母也對得上
- 開關記在裝置上（localStorage），預設唸

## 測試計畫

1. 25 題切完都有 q、1、2、3 四個檔，四段合計長度等於原檔扣掉三段靜音
2. 播放順序是問句、A、回答、B、回答、C、回答
3. 關掉開關之後只播問句與三個回答，重新整理後仍然是關的
4. 一輪十題全部按 A，檢討畫面裡答錯的「你選的」都在 A 那一行、答對的「正解」都在 A 那一行
5. 正解在畫面上的位置分散在 A B C，不是固定位置
6. 手機上從第一段接到最後一段不會中斷
